Game da Cobrinha

Um jogo da cobrinha desenvolvido em Python utilizando a biblioteca Pygame.

Sobre o projeto

Este projeto foi desenvolvido como prática de programação em Python e para aprender a utilizar a biblioteca Pygame na criação de jogos.

O jogo foi criado acompanhando um tutorial, com o objetivo de praticar e entender conceitos como:

Funções
Estruturas de repetição
Condicionais
Listas
Eventos do teclado
Movimentação de objetos
Geração aleatória de comida
Uso da biblioteca Pygame

Como jogar

Use as setas do teclado para movimentar a cobrinha:

Seta para cima
Seta para baixo
Seta para esquerda
Seta para direita

O objetivo é pegar a comida 🟩 para aumentar a pontuação e o tamanho da cobra.

O jogo termina caso a cobra bata nas bordas da tela ou nela mesma.

Tecnologias utilizadas
Python
Pygame

Como executar:
Primeiro, instale o Pygame:

pip install pygame

Depois execute o arquivo:

python "game cobrinha.py"
